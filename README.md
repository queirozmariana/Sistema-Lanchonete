## 📌 Sobre o Projeto

O **Sistema-Lanchonete** é um projeto acadêmico desenvolvido no curso de **Desenvolvimento de Sistemas**, com foco na modelagem e organização de um banco de dados para uma lanchonete.

Este repositório reúne os documentos, diagramas e scripts desenvolvidos durante o projeto, permitindo centralizar os materiais e facilitar sua consulta, manutenção e evolução.

A documentação contempla diferentes etapas da modelagem de dados, desde a representação das entidades e seus relacionamentos até a definição das estruturas do banco de dados por meio de scripts SQL.

## 🎯 Objetivos

- 📊 Desenvolver a modelagem de dados de uma lanchonete.
- 🔗 Identificar as entidades, os atributos e os relacionamentos do sistema.
- 🗂️ Organizar os dados de acordo com o modelo relacional.
- 🧩 Elaborar diagramas para representar a estrutura do banco de dados.
- 💾 Desenvolver scripts SQL para definição das estruturas do banco.
- 📚 Documentar e organizar os materiais produzidos durante o projeto.
- 🌐 Utilizar o GitHub para armazenar e versionar os arquivos.

## 📂 Estrutura do Repositório

O repositório está organizado em quatro pastas principais, destinadas aos diferentes documentos e modelos do banco de dados.

### 📊 MER — Modelo Entidade-Relacionamento

Representa conceitualmente os dados envolvidos no contexto da lanchonete, identificando as entidades, seus atributos e os relacionamentos entre elas.

Essa etapa auxilia na compreensão das informações que precisam ser armazenadas e de como elas se relacionam.

### 🔗 MLR — Modelo Lógico Relacional

Representa a organização dos dados no modelo relacional, por meio de tabelas, atributos, chaves primárias e chaves estrangeiras, conforme a estrutura definida para o projeto.

O modelo lógico serve como referência para a implementação do banco de dados.

### 🧩 DER — Diagrama Entidade-Relacionamento

Apresenta visualmente as entidades e os relacionamentos do banco de dados, facilitando a compreensão da estrutura e das ligações entre os dados.

O diagrama auxilia na análise, na documentação e na implementação do modelo de dados.

### 💾 DDL — Data Definition Language

Reúne os scripts SQL relacionados à definição das estruturas do banco de dados, como tabelas, atributos, restrições e relacionamentos.

Esses arquivos servem como referência para a criação e a organização dos objetos do banco de dados.

## 🛠️ Tecnologias e Ferramentas

As tecnologias e ferramentas relacionadas ao desenvolvimento do projeto incluem:

- **SQL:** linguagem utilizada para definir e estruturar o banco de dados.
- **Banco de Dados Relacional:** organização das informações em tabelas relacionadas.
- **GitHub:** plataforma utilizada para armazenamento, organização e versionamento dos arquivos.
- **Ferramentas de Modelagem:** utilizadas na elaboração dos modelos e diagramas do banco de dados.

## 🔄 Etapas do Desenvolvimento

O desenvolvimento do projeto envolve as seguintes etapas:

1. **Levantamento das informações:** identificação dos dados relevantes para o contexto da lanchonete.
2. **Modelagem conceitual:** identificação das entidades, dos atributos e dos relacionamentos.
3. **Modelagem lógica:** organização dos dados no modelo relacional.
4. **Elaboração dos diagramas:** representação visual da estrutura do banco de dados.
5. **Desenvolvimento dos scripts SQL:** definição das estruturas necessárias para o banco.
6. **Documentação:** organização dos arquivos e registro dos materiais produzidos.
7. **Versionamento:** armazenamento e acompanhamento das alterações utilizando o GitHub.
